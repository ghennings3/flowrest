# 🌿 Flowrest - Sua Estação de Trabalho Zen

**Flowrest** é uma plataforma de produtividade minimalista que combina a técnica Pomodoro com gestão de tarefas, tudo envolto em uma interface imersiva inspirada na calma das florestas.

---

## ✨ Funcionalidades

- ⏳ **Pomodoro Timer Inteligente**: Modos de foco e pausa com notificações visuais e sonoras.
- ✅ **Todo List Persistente**: Gerencie suas tarefas com integração em tempo real (CRUD completo).
- 🔐 **Autenticação Segura**: Login social e gestão de perfil para salvar seu progresso.
- 🎵 **Ambiente Imersivo**: Player de música integrado para sons de foco e natureza.
- 📝 **Brain Dump Widget**: Notas rápidas para capturar ideias sem perder o foco.
- 📱 **Design Ultra-Responsivo**: Experiência fluida de 3 colunas (Desktop) a 1 coluna (Mobile).

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído com o que há de mais moderno no ecossistema Web:

### Frontend & Frameworks
* **Next.js 14+**: Framework React com App Router para performance otimizada.
* **Tailwind CSS**: Estilização baseada em utilitários e Glassmorphism.
* **Lucide React**: Biblioteca de ícones minimalistas.

### Backend & Auth
* **Supabase**: PostgreSQL e Realtime Database para persistência de dados.
* **Clerk**: Gestão completa de usuários e autenticação.

### Ferramentas de Desenvolvimento
* **TypeScript**: Tipagem estática para maior segurança e escalabilidade.
